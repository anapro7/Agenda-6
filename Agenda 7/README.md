#Projeto - Consumo Água
O projeto foi estruturado para verificar o consumo médio de água dos seus clientes, com o objetivo e informar e concientizar os consumidores.
Linguagem utilizada: <img align="center" alt="Python" height="40" width="40" 
src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg"> 
Para verificar o consumo o usuário deve inserir o timpo de imóvel (ex.: casa, apartamento ou comercial), inserir o consumo médio de agua em cubagem (m3) e o sistema informará se o consumo está bom, médio o em excesso.
