#PROJETO - Calculo desconto - Agenda 6
Este projeto em Python foi criado para calcular a porcentagem de desconto conforme o valor gasto em um determinado site de compras online.
O programa solicita o *valor total da compra* e informa de acordo com o valor qual a porcentagem o cliente ganhou de desconto, realiza o calculo do desconto e informa qual valor total da compra com desconto.
